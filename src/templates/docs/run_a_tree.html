Run a tree

Your agent runs a deployed tree one question at a time. SMEme sends a question and its options, your agent finds the answer in your files and apps, and SMEme decides what comes next. At the end you get a report with the outcome, the path that led there, and the evidence behind each answer.

{% call callout("info", title="Before you start", extra_class="mb-10") %} The tree must be Deployed and Listed. Run it in a new chat, not the one where you built it. An agent that has seen the tree’s branches can be drawn toward the outcome it expects. A new chat sees only each question and its options. Your agent finds the tree by its name, so name each tree for what it decides, such as “Foreign national property tax analysis,” not “Tree 3.” {% endcall %}

Name the sources

SMEme doesn’t store your files and doesn’t read your apps. Your agent does the reading, and it can only look where it has access. That is its files, plus whatever its other connectors reach: email, a shared drive, a CRM, a ticketing system, a records system. Those are separate connectors you added to your chatbot, apart from SMEme.

Before you run a case, decide where each kind of fact lives. Ask your agent which connectors it can already read, and add the ones that hold your evidence. Then name them in the prompt. The tree’s question hints say where to look and what to avoid for each question. Your prompt says which of your sources to use. For each question SMEme sends, your agent finds the answer there and sends it back with a short reference to where it found it.

{% set prompt_id = "prompt-run" %} {% set prompt_label = "Run prompt" %} {%- set prompt_text -%} Run my [decision tree name] SMEme decision tree on this case: [one line describing the case]. First list the other apps and connectors you can already read. Then use the sources I name: [the attached files / this folder / these connected apps]. Don't look anywhere else. For each question SMEme asks, follow the hints on that question about where to look and what to avoid. Cite where each answer came from. If the evidence is missing or unclear, ask me. If I don't know either, leave it unanswered rather than guess. If two sources disagree, show me both before you answer. When SMEme returns the report, tell me the outcome, the path that led there, and the evidence behind each answer. {%- endset %} {% include "docs/_docs_prompt.html" %}

Set up your chat once

If you run the same kind of case again and again, don’t re-explain your sources every time. Put them in your chat app’s project or custom instructions, if it has them, and keep a short run prompt for each tree with your sources already filled in. The agent then starts every run knowing where facts live, what to avoid, and when to ask you.

{% set prompt_id = "prompt-standing" %} {% set prompt_label = "Standing instructions" %} {%- set prompt_text -%} When I ask you to run a SMEme decision tree, use these standing instructions. My sources, by kind of fact: - [kind of fact, e.g. contracts]: [where it lives, e.g. the Contracts folder in the shared drive] - [kind of fact, e.g. client history]: [where it lives, e.g. the CRM] - Don't use: [outdated folders, drafts, anything else to avoid] Before the first question, tell me which of these you can reach. For each question SMEme asks, follow the hints on that question, cite where each answer came from, and ask me when the evidence is missing or unclear. If I don't know either, leave the question unanswered rather than guess. If two sources disagree, show me both before you answer. {%- endset %} {% include "docs/_docs_prompt.html" %}

What a run looks like

{% include "docs/_docs_chat_mock.html" %}

Two ways to answer

The run prompt above uses the first way, which is the default. Use the second when you already have the answers for many cases. Either way, the result is the same kind of report.

One question at a time

Use this for a single case whose evidence you gather as you go. SMEme sends one question and its answer options. Your agent finds the answer in your sources and sends it back with a reference to where it found it. You can review the cited evidence and correct an answer. SMEme then decides which question matters next, and asks only the questions that can still change the outcome. The run continues until SMEme returns a report. If your agent can’t find an answer, it can leave the question unanswered, and the report says whether the outcome is settled without it.

Behind the scenes your agent uses smeme_reasoning_evaluate and smeme_reasoning_evaluate_continue.

One sheet of answers

For a batch of cases, an audit, or an automated agent pipeline, your agent can send the answers it has for a case to a decision tree in one call, instead of one question at a time. SMEme reasons over the answers you send. Questions you leave out stay open, and the report tells you whether the outcome is settled without them.

{% set prompt_id = "prompt-batch" %} {% set prompt_label = "Batch prompt" %} {%- set prompt_text -%} Load the worksheet for my [decision tree name] SMEme decision tree. For each case in [the attached files / this folder / this list], answer the questions you can from the evidence, following each question's hints on where to look and what to avoid, and cite where each answer came from. Leave a question unanswered when the evidence doesn't settle it. Send each case's answers to SMEme in one call. Then give me a table with each case, its outcome, and any questions left open. {%- endset %} {% include "docs/_docs_prompt.html" %}

Behind the scenes your agent uses smeme_reasoning_template_get, smeme_reasoning_validate_answers, and smeme_reasoning_evaluate_answers. The full list is in the MCP tool reference.

Reading the report

SMEme tells you when the answers aren’t enough, instead of guessing. Every result except Concluded tells you what to do next.

Result What it means What to do
Concluded One outcome follows from the answers. Act on it, or ask which answers decided it (see Ask more).
Several outcomes possible The answers so far don’t settle on one outcome. Answer the open questions, or ask what would settle it.
Needs more information Questions that decide the outcome are unanswered. Find the missing evidence and run again.
Answers don’t fit together Some answers can’t all be true under the tree’s rules. Recheck those answers and their sources.
Sources conflict The evidence disagrees about an answer. Decide which source to trust, then run again.

When the answers settle the outcome, the run returns a report. That report notes when the deciding answers were not independently re-checked.
