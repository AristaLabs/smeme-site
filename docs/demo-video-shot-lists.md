# Demo video shot lists

Production notes for the three demo videos referenced on the homepage and the
`/builders` page. The public pages show a "Demo coming soon" frame until each
video exists. Real product, captions on, no voiceover.

## Demo 1 · A real run: client acceptance in Claude (0:45)

Homepage, Example section. The result card beside the video is the poster frame.

1. In Claude: "Should we accept this new client?"
2. Claude reads the email thread, intake form, and client list.
3. Claude calls SMEme; the result card appears: Accept with escalation.
4. Follow-up: "What's still unresolved?" → payment terms, which can't change the decision.
5. Follow-up: "What if the scope were core services?" → Accept.

## Demo 2 · Build your first decision process (1:15)

Homepage, closing section.

1. Capture: describe the client acceptance procedure in chat.
2. The decision tree appears; adjust one branch in plain words.
3. Approve: review and deploy the tree in the SMEme dashboard.
4. Connect: add SMEme to Claude in one step.
5. See what follows: run a first case and get a result with its reasons.

## Builder demo · SMEme as a workflow step (1:00)

`/builders`, demo section.

1. A new intake form triggers the workflow.
2. The agent proposes facts from the form and email.
3. A reviewer admits them.
4. SMEme evaluates: Accept with escalation, plus the trace.
5. The workflow routes to escalation. Cut to the same step in LangGraph.
